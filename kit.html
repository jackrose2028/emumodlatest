Build your own arcade

Make this site yours: a creator's games page, a game jam's entries, a class project. Everything below goes into one file, site.json. Put it at the top of the site and every page takes its name, colours and logo, shows only the parts and systems you choose, and features your games. Then publish it free on GitHub Pages.

Publish it on GitHub Pages (free)

            
    
                
  1. Get a copy of the site. On GitHub, create a new repository (or fork this one) and upload the whole site folder. The emulator cores are large: upload only the ones for your systems from data/cores/, then run the "Update game and core indexes" action (Actions tab → Run workflow) so the core list matches.
    2. 
                
  2. Brand it. Replace site.json with yours (Add file → Upload files). If you made a branding pack, upload its assets/brand/ logo and manifest.webmanifest too. That is the only file you have to change.
    3. 
                
  3. Add your games. Put homebrew games in homebrew/<game>/ with a game.json (see homebrew/README.md), archive records in archive/, or ROM folders in data/<SYSTEM>/. The workflow builds the lists when you push. Only publish games you made or have permission to share.
    4. 
                
  4. Switch Pages on. Settings → Pages → Source: Deploy from a branch → main, folder / (root) → Save. After a minute the site is at https://your-name.github.io/repository/.
    5. 
                
  5. Optional: your own address. Settings → Pages → Custom domain, and point the domain's DNS at GitHub (a CNAME record to your-name.github.io).
    6. 
                
  6. Check it. Open the site; the start page shows your name, colours and parts. Open this page there and press "Check the published site.json" below.
    7.
