    Museum and exhibit kiosk

    For public screens and touch kiosks: an attract loop when nobody plays, an approved list of games, a time limit per visitor and a reset when a player walks away. Staff open these settings with five quick taps in the top-left corner of the screen (or Ctrl+Shift+K) and the PIN.

    Games visitors may play

    Tick the games for this screen. Games from the Homebrew showcase, the game library folders in data/ and My Collection on this device can be used.

    On this screen, in this order

    The caption is shown in the attract loop and on the game's tile (one or two sentences). How to play is shown while the game starts and behind the How to play button. Showcase games come with both filled in.

      Languages

      Leave a title or call to action empty to use the built-in wording for that language. With two languages the attract loop takes turns between them, and each game gets a second caption and How to play.

      Opening hours

      Outside these hours the screen goes dark and shows when it opens again; a game being played when it closes gets a short goodbye. With no rows the kiosk is always open.

      Staff PIN

      Offline and other screens

      Prepare for offline downloads every ticked game and its emulator core into this browser, so the kiosk keeps working without a network. It runs again each time the kiosk starts while online. Export settings saves them as kiosk.json: import it on another screen, or put it next to kiosk.html on the site so new screens start with it.
