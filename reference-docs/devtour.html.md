## What it is

The Web development case study page: a tour of the techniques this site uses, and exercises that change it.

## How it works

- A navigation column (tour stops, exercises, progress, Print the exercises, Start over) and a main column filled by `assets/devtour.js`.
- Each stop shows the real code, read live from the site's own files, and measures the value on this device.
- A hidden print area holds the exercise handout while it prints.

## Why it exists

The site is its own teaching example: every technique can be seen working, in code that can't go out of date.
