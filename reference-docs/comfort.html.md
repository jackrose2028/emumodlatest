## What it is

The Accessible and comfort play page: a game with a panel of options that make it playable for more people.

## How it works

- Markup for the game frame, the presets (Relaxed, Low vision, One hand, One switch) and the option groups.
- `assets/comfort.js` sits on the emulator's input function so every press passes through the comfort rules first.
- Settings are remembered per game.

## Why it exists

Many players need a slower game, held buttons, bigger controls or captions; this puts those options in one place.
