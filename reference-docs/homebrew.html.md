## What it is

The Homebrew showcase page: the list of homebrew games (`homebrew.html`) and each game's own page (`homebrew.html?game=<folder>`).

## How it works

- Markup for the list (search, system, sort, Random game, genre and tag filters), the game page, the publishing guide and the picture viewer dialog.
- Behaviour in `assets/homebrew.js`; the list comes from `homebrew/index.json`.
- Links to the Atom feed `homebrew/feed.xml` for feed readers.

## Why it exists

Homebrew developers publish a playable, shareable page per game by adding a folder.
