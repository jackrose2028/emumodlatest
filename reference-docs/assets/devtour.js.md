## What it is

The module behind `devtour.html`.

## How it works

- Fifteen stops: each has points, the real code (read live from the site's files, with colours, Copy and Show more), a live table measured on this device, sometimes a demo, reference doc links and a quiz.
- Eight exercises, each with hints and a Check my work that looks at the running site.
- Progress in localStorage `ejs-devtour`: stops seen, first-try quiz answers, finished exercises; Start over and a printable exercise handout.

## Why it exists

Teaches web development with a real, working site instead of toy examples.
