## What it is

The lesson content for the Classroom, as data.

## How it works

- `LESSONS`: palettes, sprites, tiles and scrolling, sound channels, memory, frames and input, binary and hex.
- Each has a 45-minute plan whose steps can carry `show` (game, view, overlay, pause, play, watched bytes), key facts, questions, a worksheet with answers and an exit ticket (`QUIZZES`).
- Adding a lesson is an exercise in the Web development case study.

## Why it exists

Keeps teaching content apart from code, so teachers can add lessons.
