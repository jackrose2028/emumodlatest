## What it is

The Site kit page: a form that writes `site.json` (name, colours, logo, parts, systems, featured games, footer, public address) while previewing the real pages.

## How it works

- Markup for the form, the preview frame and the output buttons (download site.json, branding pack).
- Behaviour in `assets/kit.js`; the preview opens real pages with `?site=` so nothing is saved until downloaded.
- A step-by-step guide for publishing a branded copy on GitHub Pages.

## Why it exists

Creators, game jams and schools can make the site their own without editing code.
