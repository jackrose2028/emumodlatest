## What it is

The branding of this copy of the site, read by every page through `assets/early-view.js`.

## How it works

- `name`, `tagline`, `logo`, `favicon`, `url` (public address, for link previews), `colors` (accent, primary, background, card, text, muted, line).
- `uses` (which parts are offered), `systems` (empty = all), `startPage`, `featured`, `footer`, `links`, `hidePlanLinks`.
- Written by the Site kit (`kit.html`).

## Why it exists

One file makes the whole site someone else's.
